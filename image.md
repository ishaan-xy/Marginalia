# Welcome to Simple Markdown
![](https://img.magnific.com/free-photo/closeup-shot-beautiful-butterfly-with-interesting-textures-orange-petaled-flower_181624-7640.jpg?semt=ais_hybrid&w=740&q=80)
A simple, open-source markdown editor — now in your browser.

## Quick start

- Type **markdown** on the left
- Hit **Preview** to see the rendered output
- Your work **autosaves** to your browser

## Formatting cheatsheet

| Syntax | Result |
|--------|--------|
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `~~strike~~` | ~~strike~~ |
| ``code`` | `code` |

### Code block

```js
function hello(name) {

}
```

> Tip: Use **New** to clear the editor, **Open** to import a .md file,
> and **Save** to download your work.
